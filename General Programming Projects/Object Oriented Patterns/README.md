# Game of Life Object Oriented Patterns
## collaborators: Sage Labesky, Vivian Tran, Anush Anand
This project demonstrates 5 different object oriented design patterns. It involves five implementation of Conway's Game of Life using these patterns. Starter code was given by our professor for the initial implementation which uses none of the design patterns.
The patterns are:
1. state
2. singleton
3. command
4. observer
5. visitor
The code was written in Java. The provided folder will compile and run when used in Eclipse IDE.
