# Sentiment Analysis experiment
## collaborators: Sage Labesky, Christy Vo
In this group project, we used a multistep process to analyze the sentiment of a collection of tweets. We built a very small AI algorithm with a small set of tweets as training data. These were assigned a sentiment and fed into a database. The words in the tweets were placed into a dictionary and assigned a score based on the sentiment of the word based on the proportion of positive and negative tweets. We then used Naive Bayes Theorem to calculate a likely sentiment of the tweet based on the words in the tweet. Finally we tested this on tweets from outside the training set. They had assigned sentiments. Whichever one Bayes got wrong we fed to OpenAI's GPT 3 API to see what it would say on the analysis. Our findings were that Naive Bayes sometimes gets sentiment wrong but the assigned sentiments were also flawed which means humans sometimes get them wrong as well. GPT 3 was correct basically every time

### To run this code you will need to libraries found in requirements.txt, a GPT 3.5 turbo API key from OpenAI set as a global variable in your computer, and if on a windows machine you will need to run the program using Docker or a Linux subsystem due to library incompatibilities.
